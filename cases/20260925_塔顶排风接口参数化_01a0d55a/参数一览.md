# 参数一览

全部长度采用 mm；孔数组合按每边包含角孔、四角去重定义。

| 变量名 | 含义 | 默认值 |
|---|---|---:|
| OUTLET_SPACING | 双圆口中心距 | 2000 |
| BRANCH_ID | 支管净内径 | 294 |
| HEADER_RATIO | 集管 / 支管内径比例 | 1.346938776 |
| BRANCH_T | 支管壁厚 | 2 |
| HEADER_T | 集管壁厚 | 2 |
| RECT_T | 矩形 / 过渡段壁厚 | 2 |
| BEND_R | 弯曲中心半径 | 450 |
| TRANSITION_L | 圆转方过渡长度 | 275 |
| CIRC_OD | 圆法兰外径 | 390 |
| CIRC_T | 圆法兰厚度 | 10 |
| CIRC_PCD | 圆法兰孔分度圆 | 345 |
| CIRC_HOLE_D | 圆法兰孔径 | 12 |
| CIRC_HOLES | 圆法兰孔数 | 8 |
| CIRC_ANGLE | 圆孔组起始角 | 0 |
| RECT_W | 矩形净宽 Z | 200 |
| RECT_H | 矩形净高 Y | 396 |
| RECT_L | 矩形直段最短长度 | 62.27789426 |
| RECT_FLANGE_EDGE | 矩形法兰边宽 | 45 |
| RECT_FLANGE_T | 矩形法兰厚度 | 10 |
| RECT_HOLE_D | 矩形法兰孔径 | 12 |
| RECT_HOLES_W | 宽边孔数（含角孔） | 4 |
| RECT_HOLES_H | 高边孔数（含角孔） | 6 |
| RECT_HOLE_EDGE | 矩形孔中心距外边 | 22.5 |

派生变量 HEADER_ID = BRANCH_ID × HEADER_RATIO。固定约束及维护方式见参数说明.md。

新增参数 RECT_BASE_OFFSET：矩形底面相对圆法兰安装面的高度差（mm），默认 0；允许正、负或零。仅要求平行，零表示共面。
