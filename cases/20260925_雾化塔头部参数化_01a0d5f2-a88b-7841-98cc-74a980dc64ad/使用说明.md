# 雾化塔进风头部

双击 **打开参数面板.cmd**。修改尺寸后点“应用并重建”；成功后自动打开新版本 SolidWorks 装配并生成 STEP。“恢复默认”只填入默认值，需再点“应用并重建”。“导出 STEP”把已应用版本复制到 exports。

默认内板 2 mm、保温棉 100 mm、外护板 1 mm。参数单位 mm；孔数为整数。Python 包安装在本目录 runtime 中的独立环境，不需要另装包；该环境仍依赖本机 Python 3.11，且需运行一个 SolidWorks 2025 实例。此目录不是跨电脑的完整软件安装包。

## 模型与参数关系

- 进风箱体的三层是真实独立实体。直段、斜面与圆筒采用法向等距生成；接口收口、固定连接平面及安装件接合处有裁切，不把局部收口尺寸解释成整层厚度。
- 法兰使用原生草图/拉伸，法兰厚度有原生尺寸方程。复杂壳体由面板脚本生成后转为 SolidWorks 原生零件；其 `INPUT_*` 全局变量是输入记录，直接编辑这些记录不会更新壳体。请通过面板修改。
- 每次成功更新生成一个新版本。旧版本保留；失败不会替换 `current.json` 指向的有效版本。组件固定在源模型坐标中，不是配合驱动装配；用户后续自建配合不会自动迁移到新版本。
- 当前原生装配路径由 `current.json` 记录，双击“打开当前装配.cmd”打开。所有依赖都在本会话目录中；固定喷枪接口可能由多个版本共享。
- 内板与外护板未指定钢材牌号，保温棉未指定密度、导热系数及等级。颜色用于分层，不能据此读取准确重量或热工性能。

## 源模型与接口边界

源参考：`D:\codex\solidworks2\case\PPG-25打包20.8.10\PPG-25-壳体.SLDPRT`。独立基准为 `baseline\头部原形独立_完整.SLDPRT`；带历史名称的早期 `头部原形独立.SLDPRT` 仅为中间拆分文件。

保留进风箱体、进口法兰、喷枪安装接口。不含塔顶盖、排风弯管、喷枪本体。中央连续实体沿源模型 **Y=4662.060493431 mm** 平面截取，作为本头部交付的下连接边界；此平面以下的连接筒及塔体不在本次输出内。

源模型存在不一致：法兰开口 296×220 mm，内风道实测净宽 285.9112966023142 mm、净高 220 mm；侧壁存在约 4.93～4.98 mm 的原始厚度，而部分板厚为 2 或 4 mm。原形基准保留这些差异，参数化版本按确认厚度重建，并统一法兰与流道开口。中央净流道采用原模型较小的实际内圆面，半径 270.11387508036555 mm。原有喷枪安装锥形座、法兰、接管保持位置和外形；重复重叠体积在派生版本中去除。

入口轴沿 X，法兰前端面保持 X=-982 mm。入口中心保持 Y=4909.060493431、Z=0 mm；原法兰外形中心 Y=4908.060493431 mm，保留二者 1 mm 偏置。入口直段初值 88 mm；改变直段长度只改变其与过渡段的分界，法兰前端和中央头部轴线均固定。

保温在喷枪安装口处由外护板返边封口；原图上的测温/检测接管位置保留 Ø19 mm 通孔，本次不包含插入流道的探杆。

内板与原锥形座修剪相交处产生的微小分离薄片按碎片处理：仅允许去除小于25 mm³的独立碎片，实际体积记录在每版 `geometry.json`；较大分离实体直接判定失败。默认版去除约5.79 mm³收口碎片。

## 默认参数

| 参数 | 默认值 |
|---|---:|
| 内板 / 保温 / 外护板 | 2 / 100 / 1 |
| 入口净宽 × 净高 | 285.9112966023142 × 220 |
| 入口直段长度 | 88 |
| 法兰外宽 × 外高 × 厚度 | 596 × 520 × 12 |
| 孔径 | 12 |
| 宽向 / 高向每边孔数（含角孔） | 7 / 6 |
| 宽向 / 高向孔距 | 91 / 94 |
| 不重复总孔数 | 22 |

修改孔数时，孔距独立输入，必要时同时调整孔距或法兰外形。角孔只计一次；至少保留 3 mm 孔边距。当前模型支持入口宽 120～450 mm、高 100～350 mm、直段 20～350 mm，内板≤10 mm、外护板≤5 mm、保温≤180 mm；组合还必须通过几何和干涉检查。

验证结果见 `验证报告.md` 和 `evidence`。STEP 回读与几何检查不替代制造图、焊接工艺、保温选型或流场性能审查。
