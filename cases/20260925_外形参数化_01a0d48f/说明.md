# PPG-25 外形与布局参数化

本目录是本会话的独立交付目录。原始文件位于项目 `case` 目录，程序不修改原始模型。新生成的零件、总装、配置和日志都保存在本目录内。

## 使用

1. 保持 SolidWorks 2025 已运行。双击 **启动参数面板.cmd**。
2. 在设备页修改尺寸，预览框架范围及标高，点击 **应用更新**。
3. 程序生成并校验一个新版本，成功后打开新总装；失败时保留上一个通过验证的版本。首次生成较慢，随后复用尺寸未变化的独立零件。
4. **读取当前参数**读取当前成功版本；**恢复基准参数**只填回基准数值，再点击应用才更新模型。

当前版本路径见 `current.json`。`models/library` 是本会话内部的独立原生零件库，`models/versions` 保存各次布局总装及验证记录。请整体保留本目录，不能只移动版本总装文件。

面板通过本机 Python 3.11 和 pywin32 连接 SolidWorks 2025。启动器检查运行时并写入 `runtime/launcher.log`，界面和生成日志在 `runtime/panel.log`。本目录不包含 SolidWorks 或 Python 安装程序。

## 参数入口与原生模型

长度为 mm，角度为度。中文标签对应稳定英文参数名，完整清单、初值与允许输入范围见 `parameters.schema.json`。面板是整机布局的统一参数入口。

设备零件由可编辑草图、拉伸、拔模和旋转特征构成。草图直径、长宽、特征高度及偏移绑定零件方程。锥度及派生位置由面板计算。整机组件定位由脚本计算后固定，不是原生配合自动解算。直接在零件方程中手改不会驱动整个布局；再次在面板应用时仍以面板参数为准。

总装中的 `LAYOUT_*` 全局变量记录框架范围与标高等派生结果，用于查看；整机输入以面板中的英文参数标识为准。

不同参数版本复用未改变的库零件。若要对库零件人工做二次设计，应先另存副本，避免影响其他版本。程序会检查复用零件的文件完整性。

为控制 SolidWorks 窗口占用，更新前会关闭本会话旧的输出窗口。未保存的输出工作副本先另存到 `runtime/working_copy_backup_*`，再重新读取已验证文件；源参考文档不在此处理范围内。

## 基准与简化

源装配包含两级旋风；两级均保留，参数独立。源塔保温外壳外径约 2700.09 mm，内筒约 2500.09 mm，本模型采用保温外径。坐标方向沿用源总装，Y 竖直，原框架最低点平移为 Y=0。

塔底收料出口标高固定为 546.66 mm。下部收料筒及过渡段决定主塔锥底标高；塔下锥增高会抬高支撑层和其上设备，直筒增高只抬高塔顶及相关连接。加热箱和地面风机保留原安装层位置。

外形测量记录见 `evidence/source_inventory.json` 和 `evidence/analytic_profiles.json`。包围盒仅用于外形盘点，旋转主体主要尺寸取解析圆柱/圆锥面，非制造公差验收。简化后的风机采用圆形壳体、切向出口、电机和底座表达占位；小附件、保温层内部、叶轮、加热丝、螺栓均省略。

主热风方管转角简化为方弯外形；圆风管采用原生弯头与直管。接口过渡用于外形布置，不是钣金展开或压力管道设计。

风机接口可调高度及绕竖轴方位，电机随本体朝向变化；小支管按接口中心斜接表达外形，未细化密封端面。主加热器上接口可调左右、前后偏移。塔支撑偏移与下、中层梁标高可以分别调整；主动调整安装层标高时，其上的设备随层移动。

## 验证边界

实心外形体积只用于核对几何生成，不代表材料用量。没有进行热负荷、流量、压降、风机选型、框架强度或制造图设计。输入上下限只是初步参数边界；通过验证的变更组合以最终验证报告为准。

源装配未保存的修改保持原状。所有交付引用须位于本会话目录内，不引用源零件或临时导入零件。
