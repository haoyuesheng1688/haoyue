# 雾化塔进风头部参数化复盘

整理日期：2026-09-26。检索标记：PPG25_INLET_HEAD_LAYERED_20260926。
本次只读核对保存的报告、JSON 与实现脚本，未重新运行 CAD 验证。下述结果属于证据记录的交付版本，不代表当前活动 SolidWorks 状态。

## 范围、基准与实现边界

- [scope] 进风箱体、进口法兰、喷枪安装接口；排风弯管、塔顶盖、喷枪本体不在范围内。
- [decision] 保持净流道，内板/保温/外护板为 2/100/1 mm，向外增厚。入口前端及塔体连接基准固定。
- [implementation] 三层壳体为脚本生成并导入的 BRep；法兰为原生草图/拉伸；组件按固定坐标定位。壳体 INPUT_* 仅记录输入，必须经面板更新。不能描述为完整原生特征、配合驱动或可展开钣金。
- [boundary] 未指定完整材料/保温物性，未验证喷枪全行程、制造图、热工或 CFD。体积不等于可靠重量。
- [portability] 本地 runtime/venv 仍依赖本机 Python 3.11 和 SolidWorks；不是跨机完整安装包。

## 源几何与参数语义

源为 case/PPG-25打包20.8.10 的 PPG-25-壳体.SLDPRT 及 PPG-25.SLDASM。原多实体零件中，中央头部与下部结构共体；仅筛选上方实体会遗漏它。完整原形基准补入副本沿 Y=4662.060493431 mm 截取的中央结构。该坐标仅属于此案例。

源法兰开口 296×220 mm，实际流道净宽 285.9112966023142 mm、高 220 mm，原板厚不一致。原形副本保留差异，参数化版本统一法兰开口与流道，并应用确认的三层厚度。净流道圆面半径 270.11387508036555 mm；修正重叠几何不代表完全同形复制。

|关键词|默认值与含义|
|---|---|
|INNER_WALL_MM / INSULATION_MM / OUTER_SKIN_MM|2 / 100 / 1 mm，主壁法向厚度|
|INLET_W_MM / INLET_H_MM|285.9112966023142 / 220 mm，净尺寸|
|INLET_STRAIGHT_MM|88 mm，改变直段与过渡段分界|
|FLANGE_W_MM / FLANGE_H_MM / FLANGE_T_MM|596 / 520 / 12 mm|
|HOLE_D_MM|12 mm|
|HOLES_W / HOLES_H|7 / 6，每边包含角孔|
|PITCH_W_MM / PITCH_H_MM|91 / 94 mm，独立输入|

入口前端 X=-982 mm，入口中心 Y=4909.060493431 mm、Z=0，法兰外形中心 Y=4908.060493431 mm；保留源 1 mm 偏心。不重复孔数为 2Nw+2Nh-4=22。所有默认值与适用范围仅属于本案例。

## 踩坑及处理

|问题|处理|复用边界|
|---|---|---|
|上部包围盒筛选漏中央共体|追踪解析面，在复制实体上沿连接平面截取|不得沿用固定 Y 值或实体序号|
|斜面按竖向增量增厚|采用法向偏移及交线，三层包络作差|收口和截断位置单独检查|
|布尔后 clean 导致形体失效|保留独立副本，减少不必要清理，前后检查有效性|不是所有 clean 都有问题|
|喷枪口保温暴露/交叠|增加外护板返边，同步从保温扣除|须保留安装空间及检测通孔|
|内板相交处产生独立薄片|本例默认约 5.79 mm³，位置与原因有记录后移除|代码 25 mm³ 阈值仅为本例，不能推广成删除小实体规则|
|STEP 被模板选择窗口阻塞|限定导入作用域，显式模板/多实体零件设置，finally 恢复偏好|枚举整数、模板路径须按当前安装核对|
|导入对象不是零件|先检查 GetType，再转换 IPartDoc|取消导入后不能继续假设有效对象|
|模板使保温继承 AISI 304|清除本次未指定材料的层件错误继承并回读|固定附件中仍存在 AISI 304 记录，不能把所有材料都说成空白或已认证|
|当前装配复用旧版附件|递归引用核对，保留依赖目录|清理旧版前必须按依赖判断|
|生成失败破坏当前入口|候选版本验证保存后才提交 current.json|失败保留上一有效版本，COM 更新串行|
