# 旋风分离器 R4：等面积、可调方位与偏心斜切复盘

记录日期：2026-09-20。检索标记：CYCLONE_R4_ECCENTRIC_EQUAL_AREA_20260920。
用户已明确认可R4结果，并要求整理知识库、优化skill和记录避坑。

## 最终需求，覆盖早期解释

- [requirement] 输入等效圆直径，换算矩形进口净面积；高宽比默认2.5，主体依截图比例缩放，再允许独立微调。
- [requirement] 侧气体出口与微调后的矩形进口净面积相等。旧174/259侧管/竖管内径比例已取消，不能再把它当最终驱动规则。
- [requirement] 进口与出口方位角分别可调，开口、接管、法兰和孔组同步。
- [requirement] 侧出口不是从总管中心径向引出，而是偏心相贯斜切。用户在二选一中确认“按外侧齐边计算偏心距”。
- [requirement] 2 mm表示模型尺寸验收允许误差，不表示板厚、连接间隙或面积容差。
- [scope] 本次认可针对几何及参数化交付；不表示完成CFD、结构强度或制造认证。

## 参数模型

```text
A0 = pi*d²/4
b0 = sqrt(A0/r); h0 = r*b0
b = b0+Δb; h = h0+Δh
side_ID = sqrt(4*b*h/pi)
e = (main_OD-side_OD)/2+Δe
```

两管等壁厚时，偏心公式可用内径差的一半。零偏心微调满足`e+side_OD/2=main_OD/2`；壁厚不同时不可继续用内径差简式。大幅微调或side_OD≥main_OD须重新判断几何适用性。

R4关键词：`等效圆直径`、`进口高宽比`、`进口宽微调`、`进口高微调`、`进口方位角`、`出口方位角`、`排气侧管直径`、`排气偏心距`、`排气偏心微调`、各法兰尺寸和孔组参数。

坐标：总管轴Y；接口向外轴线+Z为0°，+X为90°，-Z为180°，-X为270°。进口气流方向与进口向外轴线相反。侧出口0°时向-X偏心；90°时向+Z偏心。两角度描述周向方位，不是管道仰角，也不是偏心量。

## 需求理解的主要教训

|版本/问题|错误或不足|最终处理|
|---|---|---|
|R1放大到219 mm|侧管径随比例放大，但上部腔高固定350 mm，侧法兰与盖板干涉|腔高/外伸/法兰包络联动，逐个工况做实际干涉检查|
|R2侧管比例|参考件两管比例曾被采纳，但用户后来明确要求进出口等面积|公式改用微调后的进口净宽高，删除冲突的侧管径独立微调|
|R3水平侧出|把“侧出”理解为水平+可调方位，仍从总管中心引出|R4明确偏心，用户确认外侧齐边，偏心支管、开孔、法兰、孔组一起变|
|只看透视图|容易把轴线方向与轴线位置混为一谈|解析圆柱面回读轴线，用俯视图和局部图交叉核对|

参考原件曾回读到竖管内径259 mm、侧管内径174 mm、轴线偏心约43 mm。这些仅用于解释历史参考，最终R4偏心公式按用户确认的齐边约束计算，不继续按43/259比例缩放。

## 实现与避坑

- [pitfall] `InsertMoveCopyBody2`旧式XYZ旋转未产生可枚举的驱动尺寸。启用Euler模式并提交后，才出现本机中文`偏航/俯仰/滚转`尺寸。方程驱动偏航后用真实轴线验证，不声称只是写了全局变量就已联动。
- [pitfall] 本机直接新增零角方程失败，采用`偏航=方位角+360`并测试0°及多角度。仅为实测兼容处理，不推断所有版本禁止零角。
- [pitfall] 修改未激活文档的方程曾出现读数变化而几何未变化。先ActivateDoc3并按完整路径重新绑定；证明母件实际变化后才比较组件，避免两个旧体积相同的假通过。
- [pitfall] 刚体旋转不改变体积。装配角度联动必须用轴线、点坐标或六向极值；本案组件为共同原点，任意装配还需考虑组件变换矩阵。
- [pitfall] 草图点自动合并会产生冗余参考尺寸。方程控制状态下的DrivenState不能直接用于区分参考尺寸；先在受控副本备份并解除相关方程，剔除重复参考驱动。不要强制所有尺寸为驱动。
- [pitfall] 偏心修改不能只拖圆心：原竖直构造线仍锁定x=0。仅删除相应竖直关系、旧位置/参考尺寸，保留圆径及其他约束，新增独立水平/竖直尺寸；三个修改草图均验收为完全定义。
- [pitfall] `SetEquation`返回None不是失败；使用方程回读和实际几何判断。`Add2`返回索引，应分别处理。
- [pitfall] 动态COM无参属性与方法不同，GetEdges/GetFaces可能直接返回tuple；使用已有value()适配器。SolidWorks数学函数本机用`sqr`，Python用`sqrt`。
- [pitfall] 同目录之外的同名零件也可能不能同时打开；各版用唯一文件名。保存实体特征本机类型为`CreateAssemFeat`，副本必须解除旧输出再生成自己的关联文件。
- [pitfall] Save Bodies后实体名变化，不能靠旧Body.Name做验收。按几何或持久引用识别，体积相同的实体不能仅用体积排序配对。
- [pitfall] GetBodyBox是近似值，只适合粗筛。精确检查使用解析面、净口角点和GetExtremePoint。
- [pitfall] STEP小幅体积差不等于失败，但也不能只凭体积近似就通过；结合有效实体、孔口、解析面、极值及尺寸。六向极值一致也不能单独证明内部拓扑全同。
- [pitfall] ViewZoomTo2曾把局部图裁掉出口。选择上部实体后ViewZoomToSelection、清选择、SaveBMP，再实际看图；更换预览后重新打包。
- [optimization] 批量修改只写变化方程，缓存变量索引，求值和重建集中执行并恢复原设置。不要每改一个变量都重新扫描或重写所有方程。
- [optimization] 工程脚本中的PID22412、旧安装类型库和模板路径只是历史绑定，复用时重新盘点会话。一次性修复脚本不当作通用生成器分发。
