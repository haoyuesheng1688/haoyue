# DXF 旋转座体、独立组件及装配验证

适用于从二维安装剖面构建座体、锥壳、法兰，并与已有设备装配的任务。来自 SW2025 实测；尺寸、PID、模板路径及用户容差都是案例数据，不得固定复用。

## 先解决截面含义和接口
- 从 DXF 的 INSUNITS、明确标注及实际几何交叉验证单位与比例。大型总图按图号、邻接尺寸定位，不以首次搜到的相似剖面作依据。
- INSERT 图块需要递归展开并应用插入变换，转换到设备共同局部坐标。相邻图块可能重复同一轮廓；按几何、构件作用和所属视图去重，不能每条轮廓都建一层实体。白色 CAD 线用深色底检查。
- 实体座体、薄壁壳体、保温层、未剖投影线必须分清。长横线经过轴心不必然代表实心圆盘。主要结构含义缺失时先澄清；明确定义的其他部件可以继续。
- 截面中两个螺栓位置不能推导整圈孔数。分别记录 PCD、孔径/螺纹、数量、角向位置、孔深；缺失量保持待定。
- 画零件前对照接口表：零件A外径、零件B内径、接触标高、间隙及来源。直径标注归属不清时结合尺寸界线与剖面判断，不用旧模型的解释替代原图。

## 原生参数和旋转特征
- 闭合径向-轴向剖面绕中心轴旋转，保留全局变量→草图尺寸→特征的真实依赖。大量构造线时，旋转轴显式选择 mark=4，避免自动选中错误的构造线。
- 锥壳斜率 k=(r_top-r_bottom)/(y_top-y_bottom)，同高径向厚度 dr=t*sqrt(1+k²)。明确基准是流道净面、内表面或外表面，再决定偏置正负；不要将 dr 当作法向板厚 t。
- 本次 SW 方程平方根采用 SQR，指数采用 ^。单位保持一致，API几何单位m与图纸mm显式转换。
- 方程中登记了参数但尚未建孔或阵列时，标明仅记录参数。独立组件各有方程，不代表已经跨组件同步或跟随整机缩放。

## 关键故障：非活动文档的假通过
症状：SetEquation 后方程已显示3mm，ForceRebuild3无错误，但实际圆边与体积仍是2mm几何。本次先激活目标零件后重测，才读到3mm。

操作方式：按完整路径获取并核对目标，ActivateDoc3激活，重新绑定该文档的IModelDoc2/IEquationMgr，修改方程、EvaluateAll、ForceRebuild3，再读实际几何。保存/检查函数若依赖当前活动文档，也应检查绑定身份。

做 A→B→A 测试：B状态必须实测发生预期变化，恢复A后比较实际尺寸、实体数、体积。仅方程字符串改变或重建无报错，不是参数联动通过。激活解决过本次问题，但不要将全部更新失败都归因于非活动文档。

## 圆锥及周期几何回读
- 完整旋转体可能没有顶点，GetVertices返回None并非无效实体。改读 GetEdges→GetCurve→IsCircle→CircleParams，以解析圆半径和圆心轴向标高复核截面。
- 圆心、轴方向需先验证；只有轴沿模型Y时才直接用CircleParams的Y值。一般旋转轴使用坐标变换或轴向投影。
- 从两端实际圆半径求实际锥面斜率，再计算实际法向厚度；不要用输入方程值代替几何回读。
- GetBodyBox只用于宽相碰撞筛选或粗定位，不能作为精确尺寸验收。

## 组件化与装配检查
- 按制造/修改边界拆分座体、内外壳、法兰、参考包络。共同原点固定定位能减少易失效的面引用，但应明确它不是已建立同轴/接触配合的装配。
- 在扩展附件细节前尽早与已有设备做总装干涉检查。独立零件正常不代表总装能装入；旧导叶等高假设可能与新座体外形冲突。
- 嵌套装配只对零件取实体；将副本变换到同一装配坐标系。验证Transform2或总变换的坐标口径，不能把本次子装配单位变换的巧合推广到任意层级。
- 在临时实体副本上做布尔求交；记录运算状态和重叠体积。内核失败不得记为零干涉，宽相筛选也不是最终通过。
- 区分制造实体穿透、面接触、参考包络内部有意重叠。包络透明或排除BOM不自动从所有导出/质量统计中排除；报告包含范围。
- 若需修正既有组件，优先在副本中调整种子特征再由原阵列传播；是否属于本次范围依据用户指令，不因本案例另设通用审批步骤。

## STEP 导入、视觉与闭环
- 导出成功后在SolidWorks重新导入，对比实体数、有效性、体积。记录模型版本与包含的参考包络，任何后续几何修改都会使旧验证记录过期。
- 默认模板偏好只能作为降低弹窗概率的措施，不能保证LoadFile4无弹窗。本次设置了默认零件/装配模板及AlwaysUseDefaultTemplates，仍出现“新建SOLIDWORKS文件”。先看窗口状态，不把COM等待直接判为崩溃或死循环。
- 弹窗使用当前电脑控制技能规定的API处理；从当前窗口状态选择模板。多屏/从属对话框坐标使用最新截图ID与该图的局部坐标。截图被其他窗口遮挡时，激活已确认的目标窗口再观察，不能根据旧坐标盲点。
- 临时应用偏好应保存旧值并在finally恢复。只关闭本次拥有且身份明确的导入文档，保留用户未保存文档。
- 原生保存重开、STEP回读、干涉检查是三个独立结论。新增包络等改变后更新统计和对应验证，避免引用较早版本的实体数量。

## 误差表与交付口径
至少记录：部件/特征、检查量、来源与证据等级、基准值、实际值、单位、偏差、是否设计适配、适用容差、结论、剩余问题。
区分复现误差与有意改型：单边+2mm是直径+4mm，不能统称“尺寸误差2mm”。形状容差不自动扩展到板厚、安装接口、负间隙或干涉。
用户认可成果或要求沉淀经验，不等于已确认未定孔数、材料、全部装配干涉或生产批准。保留已验证、条件成立及待处理三类状态。
