# 多实体分割失效与参数更新效率

适用：已有零件含 Split、Move Face、镜向、放样等特征，改中心距/管径后出现实体消失、余料留下或下游连锁错误。来自 SW2025 SP5 塔顶排风接口案例；版本、特征名、尺寸和阈值均非跨项目常量。

## 先把错误定位到几何

1. 记录用户失败参数，绑定准确实例和完整输出路径；在一个可追踪的副本复现，保护源文档。
2. 检查最早出错的特征及前一个特征的结果。后续草图、基准面和钣金报错可能只是连锁反应，不逐个盲修。
3. 如果是分割/裁剪，记录输入和输出实体的角色、解析面、体积，以及保留/消耗标志。名称、数组索引和旧点击位置不足以证明实体身份；简单外形也可能带有不稳定的历史引用。
4. 将重建前后实测与设计意图比较：管段、集管、余料是否对应正确。错误码为零仍可能保留了错误实体。

## API 返回值的证据边界

- 修改定义后，释放或恢复选择访问，重新取得特征定义，再读取属性和实体结果。`ModifyDefinition=True`、方程字符串变化或没有异常不等于几何更新。
- 本案例中，分步增加中心距仍在后续范围失效；部分 `SetSplitBodies` 调用没有改变回读标志。它们是此模型/绑定的失败尝试，不能写成该 API 在所有版本都无效。
- 同一尝试再次得到相同标志和相同错误实体时，停止无变化的重试，转查实体身份、引用和拓扑。不要堆叠 API 包装或只放宽容差。
- `AccessSelections` 可能回滚特征树；异常路径也要恢复状态。类型化 COM 的空对象、SAFEARRAY 和动态包装应按实际签名处理，避免从单次试验提炼通用调用模板。

## 可选的局部修复

本案例有效路径：保留分割结果 → 按当前几何识别两支管、集管及余料 → 原生删除实体特征去除余料 → 完整重建和回读。保留了扫描、镜向、抽壳和钣金放样。

- 只在能够唯一识别角色时采用；结合解析面/连接位置/拓扑/体积，不普遍按“最大体积即保留”。本例用圆环面识别弯支管、集管轴线与圆柱面筛选集管。
- 本例修复分支用 `abs(OUTLET_SPACING-2000)>100` 分流，以保持已验证小范围路径不变。这是局部兼容实现，不是几何安全区间；不要复制为新模型的限制或声称已验证所有大尺寸。
- 本例脚本含工具圆柱修剪的后备路径，但已核对的 2500 mm 默认工况记录 `trimmed=[]`；不能因此声称后备路径已经验证。未触发的分支须单独验证后才能推广。
- 如果旧引用持续阻碍可靠联动，再考虑局部重构或对称骨架重建。保留历史特征和重构各有成本，应以可验证的几何和维护成本决定。

## 共面、平行和容差

- 共面要求法向平行且有符号平面间距为零；只要求平行时，高度差可独立输入。矩形出口法兰端面的方向不要与矩形风道下侧外平面混淆。
- 使用统一标高公式。例如本例 `RECT_BOTTOM_Y=-CIRC_T+RECT_BASE_OFFSET`，矩形高度向上增长，内腔按壁厚补偿；三个面需从实际平面法向和位置回读，而不是只检查公式。
- `RECT_BASE_OFFSET=0` 是共面；正负值分别升高/降低。修改高度差后，流道检查的出口中心点也要同步，不继续使用旧标高的射线终点。
- 用户允许 2 mm 尺寸误差，不表示允许缺实体、错误壁厚、自动增大间隙或封堵。精度要求按项目确定；本例保留 0.01 mm 检查是验证结果，不是所有任务的强制门槛。

## 少走弯路的验证顺序

1. 小案例先跑用户实际目标值；没有范围时说明只验证了哪些值，不以微小扰动代替目标范围。
2. 定位阶段只回读首个失效特征与其必要几何，保留同一副本和前后快照。
3. 修复后验证目标工况及有区分度的组合：本例为 2500 mm、非零高度差、较大支管加非等比矩形，再恢复默认工况。未受影响的旧回归可引用并明确是历史记录。
4. 最后在实际面板入口提交，验证失败恢复、输出文件的保存重开和 STEP 回读。原生和导入文档可能同名，激活后核对完整路径；导入件先另存为唯一测试文件。
5. 记录连接、参数更新、重建、几何检查、导出及回读耗时。未计时就不能断言某部分占大多数时间；本次重复探测、API 无效尝试和多轮完整重建确实增加了累计耗时。
6. CAD 修改在同一实例串行运行。关闭已经结束且明确属于本次测试的文档；不关闭或保存源文档，不将窗口前后台状态未经对照测试就归因为性能瓶颈。

## 交付与测量陷阱

- STEP 可能把一个周期圆柱面拆成多个面片；孔数应按轴线和半径归并，而非简单数面。
- 原生/STEP 体积差异先核对几何与积分精度。本例采用 `IMassProperty2`、`AccuracyLevel=2`、SI 单位逐体积复核；不能为通过测试任意放宽容差。
- 默认参数、当前参数、历史验收和当前 STEP 要分别标识。当前模型保留用户目标 2500 mm，默认值仍是 2000 mm，不把“做过恢复测试”写成“最终仍为默认值”。
- 焊缝、钣金开缝和原件局部相交单独记录。中心折线路径通过不等于全截面流通、气密、压降或展开制造验收。
