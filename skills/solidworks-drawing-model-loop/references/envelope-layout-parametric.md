# 整机外形与布局参数化

适用：从已有装配提取独立设备外形，交付可编辑原生零件、布局总装和参数面板。依据 PPG-25 在 SolidWorks 2025 SP5 的实测；具体尺寸、轴向、端口拓扑和许可重叠必须重新盘点。

## 先保护源与建立基准

- 重新绑定实际实例、版本和完整文档路径。按项目规则建立会话目录；同一会话继续使用原目录，源参考只读。
- 磁盘哈希不能保护尚未保存的模型。另记录源文档未保存标记、组件路径/抑制状态/变换，以及盘点范围内实体名称、数量、面数和局部包围盒。完成后比较；不要为验证而保存、重建或关闭未保存源文档。
- 实体名不一定唯一。源基准匹配采用组件身份和名称分组内的几何多重集，不能用 name→body 字典丢掉重名实体；无法唯一确认时报告范围，不伪造一一对应。
- 区分已测尺寸和简化假设，建立设备、端口、支撑层、连接拓扑的对应表。外形体积不代表材料，端口占位不代表内部流道通畅。

## 同一参数源与有向依赖

- 稳定英文 key 配中文标签，明确 mm、度及 API 单位换算。由同一参数对象生成实体、端口和布局；全局变量必须链接原生尺寸。
- 设备自身尺寸与布置规则分开定义。选择实际设计基准：例如塔轴线和出料标高固定、塔增高向上；这些是本案例约定，其他设备应按用户意图定义。
- 以外形和净距计算邻机位置；读取源净距，不能自动增加所谓检修空间。框架范围包含旋转后设备及电机占位；支撑层随明确的支撑基准联动。
- 保留连接顺序和布置侧。按端口坐标求直段、弯头、过渡；负管长、弯头空间不足、端口不连续或新增非预期碰撞应指出具体对象并拒绝提交，不任意绕管。
- 不用整机同比缩放替代壳体、电机和接口的独立参数。明确面板“应用更新”重排与原生配合驱动的差别；不要引入用户未要求的后台监控。

## 小案例、版本与真实入口

先打通一个依赖链：塔径 A→B→A，观察旋风外移、管道改变、框架扩大和恢复。确认实际实体与变换后再扩展其余设备。

- CAD 写入串行化。生成新的版本，检查通过才原子替换 current 指针；失败保留上一成功版本。若复用零件缓存，用几何输入和内容校验识别，不将用户改过的缓存默认为可信。
- 所有新装配引用回读至当前会话根目录。关闭仅限身份已核对的输出；本会话未保存输出也要先保护副本。
- 面板应能读取当前、应用、恢复基准、显示错误和日志。明确“恢复基准”是只填值还是立刻应用。启动器需处理中文路径、编码、错误反馈及工作目录。
- 验证分层：纯布局计算、原生零件方程、完整生成进程、面板真实字段/按钮回调、桌面鼠标操作。按钮 invoke 测试不等于鼠标验收；桌面失联时保留已完成证据，标记剩余鼠标步骤，不用坐标盲点或伪称通过。

## 原生几何与验收

- 逐项及组合改变塔径/筒高/锥高、加热器各轴尺寸、旋风、风机壳体/电机/接口、支撑层。记录实际通过的离散配置；字段允许范围不意味着范围内所有组合可行。
- A→B→A 独立重开各版本，检查实际尺寸、组件变换、接口连续性、净距和框架；不能只比较 JSON 或方程文本。
- 精确外形使用解析尺寸或实体方向极值。使用 GetExtremePoint 时将装配世界方向转换到零件局部方向，返回点再转换到世界坐标；旋转件不能只变换局部包围盒的两个角。源近似包围盒可用作同状态保护快照，但不能当加工精度证明。
- 干涉许可按特定对象对、位置和重叠范围记录；本外形案例的端口/支承重叠不应变成所有项目的全局豁免。说明是否排除单个多实体零件内部重叠。
- 保存、关闭并重开输出总装。导出 STEP 后实际导入回读，避免借用仍打开的同名原生文档；比较实体数、体积、世界包络，记录错误和警告码，恢复临时修改的导入选项。
- 检查整体、俯视及关键连接视图；生成图片不等于已检查。交付完整引用目录和唯一当前入口，区分试验、失败版本及最终文件。

## 本机实测故障与适用边界

|现象|处理与边界|
|---|---|
|选错活动文档后草图/方程错位|每次操作先激活并核对完整目标路径；保留新建文档返回对象|
|矩形改长宽后仍相等或漂移|本案例改用角点矩形、固定基准角，去除新草图自动生成的等长关系；关系枚举按安装版本核对，不能把历史值14当通用删除规则|
|圆直径方程写入但几何未动|固定圆心，确认尺寸是驱动尺寸并链接方程；在独立副本进行实体A→B→A|
|颜色/透明度异常|MaterialPropertyValues 使用 VT_ARRAY\|VT_R8 数组并回读；原始 tuple 在此环境曾产生异常，不推断所有接口都相同|
|缩小视图却偏离中心|本机 view.Scale2 与 Translation3 同比例调整，并经 IMathUtility.CreateVector 写入 R8 数组；跨版本先小图验证，视觉复查边距|
|源体比较误报改变|源零件含重名实体，改为保留重复项的几何匹配；修正比较器后重新验证，不把误报直接认定为模型损坏|
