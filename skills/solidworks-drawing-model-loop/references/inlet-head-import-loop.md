# 进风头部：共体截取、分层重建与导入闭环

与 [独立系统提取](insulated-system-extraction.md) 配合使用。本参考来自 PPG-25 头部在 SolidWorks 2025 SP5 / CadQuery 2.6.1 的案例；不把案例坐标、模板路径、枚举整数或碎片阈值作为通用配置。

## 先识别完整边界

- 包围盒筛选只能定位候选实体。头部可能与塔体连成一个实体，完全位于上方的实体集合会漏掉中央结构。沿接口追踪解析面，并对跨界实体记录分割平面、保留侧和所属接口。
- 对 `IBody2.Copy` 的副本做临时 Boolean，再创建独立零件；不要修改源 body。原形基准应包含被截取的共体部分，记录分割前后数量、体积与位置。早期不完整基准明确标为中间结果。
- 源法兰开口与内风道不一致时，分别测量并记录。原形副本保留差异，重建版依确认的流道/厚度规则联动；不能称两者完全同形。
- 源文件因占用无法普通读取时，可用 Win32 共享读写方式只读流式计算哈希，失败则报告。不要为计算哈希关闭或保存源；磁盘哈希与未保存内存状态是两项证据。

## 生成与布尔操作

- 定义净流道包络及逐层法向偏移包络，以相邻包络差集生成内板、保温和外护板。斜面不能只增加竖向厚度；求偏移面交线并检查短边、自交、断体。固定接口平面的裁切与局部收口单独验收。
- 安装口返边封住保温时，从保温中扣除返边占据体积；同时检查喷枪安装空间、检测口及法兰孔组。
- CadQuery/OCC 的 `clean()` 在本案例部分布尔结果上使有效形体失效。仅在需要时清理，并比较前后有效性；可能共享底层拓扑的“原对象”不一定是可靠回退，先保留独立副本。不要推导为全部 `clean()` 都禁止。
- 对重复使用的布尔操作数显式复制；切除前证明有交集，无交集可跳过。量级阈值来自本项目尺度，不复制历史数字。
- 分离碎片先检查拓扑位置、形成原因和功能，再决定拒绝或有记录地移除。体积小不等于可删除；孔边、密封边和薄板不能用统一体积阈值清扫。

## STEP 导入的有界处理

出现停滞、类型转换失败或意外材料时，先检查模态模板窗口、导入返回对象和偏好设置，避免连续重试造成文档堆积。

1. 从当前安装类型库核对枚举名称与可用 API，发现实际零件/装配模板路径。
2. 快照相关偏好。需要无外部关联的多实体零件时，在当前导入作用域配置 `swMultiCAD_Enable3DInterconnect`、`swAlwaysUseDefaultTemplates`、`swImportMultBodyAsPartData`、`swImportNeutralAssemblyStructureMapping` 及默认零件/装配模板。
3. 用 `GetImportFileData` / `LoadFile4` 导入，先检查空对象、错误和 `GetType`，再转换 `IPartDoc`。所有修改的偏好放在 `finally` 中恢复；不要持久改变用户设置。
4. 回读实体数、体积、材料和依赖。模板可能让保温实体继承钢材；仅对本次新建且未指定材料的输出去除错误继承，并再次回读。源附件材料与用户指定材料另行处理。

历史枚举整数仅能作为排障线索；其他版本重新核对。导出成功不能代替 SolidWorks 重新导入验收。

## 证据级别与版本承诺

|证据|可证明|不能推导|
|---|---|---|
|几何引擎同代码 A→B→A|生成器对应工况的尺寸/体积恢复|每个工况都通过 SolidWorks 重建|
|分别生成原生 A/B/A 文件后回读|生成式入口的小案例闭环|同一文档修改方程后自动联动|
|真实面板操作更新、恢复|控件到生成器链路可用|开发中修改算法前后的 A 体积必须相同|
|最终装配与 STEP 重开|该保存版本交换一致性|全部参数组合、制造或流场性能已验证|

壳体由脚本生成 BRep、法兰保留原生草图特征、装配用固定变换时，如实说明混合实现。`INPUT_*` 审计变量不具备几何驱动能力；原生文件后缀不代表完整特征历史、原生配合或可展开钣金。

成功指针只在候选版本检查、保存完成后提交。清理历史目录前遍历当前装配的递归依赖：旧版本固定附件可能仍被最新装配使用。本地 venv 可能依赖本机基础 Python，不能因此称为跨电脑自包含安装包。
