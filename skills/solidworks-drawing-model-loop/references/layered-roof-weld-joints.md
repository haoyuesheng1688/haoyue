# 多层顶盖、接管与筒壁焊接参数化

适用：已有装配独立提取、保温分层壳体、浅锥顶盖、穿保温接管、参数面板与版本迁移。以下公式以同轴圆筒和直母线锥面为前提，不适用于任意封头。具体尺寸、PID、模板和旧脚本路径均须重新读取。

## 先识别真实连接

- 独立成零件是建模组织方式，不能据此将焊接边界改成可拆法兰。先看源剖面、解析面及用户确认，区分对接焊、搭接、法兰、加强圈、保温收口。
- 用户确认内外板分别焊接时，让内板与内筒、外板与外筒各自连续；不要把所有层强行裁在同一标高，再凭空补裙边或厚环板。
- 顶盖与筒壁的环焊连接，不等于顶盖上的接管法兰也要取消。范围变化要按具体接口传播。
- 保温与金属接触，不能描述为保温焊接。原生装配可保留板件分件并注明焊接关系；验证用几何合并与实际交付的焊接特征/实体合并须明确区分。未指定时不臆造坡口、余高和工艺参数。

## 法向厚度与直接对接几何

定义内流道圆筒半径R、中央开口半径C、顶盖内锥升高H；主体内侧上口为y=0，y向上。令s=H/(R-C)，q=sqrt(1+s²)。

```text
内锥：y(r) = s*(R-r)
距内锥法向累计厚度t的锥面：y_t(r) = s*(R-r) + t*q
筒壁第i条分层边界半径r_i：按筒壁自己的累计径向厚度计算
同层直接对接点：(r_i, s*(R-r_i) + t_i*q)
```

- 顶盖厚度和筒壁厚度可独立，但共享对应层的对接边。用相同端点分别构造顶盖闭合剖面和筒段上缘；内流道对接点仍为(R,0)，外侧接缝通常不在y=0。
- 相邻平行锥面的轴向截距差除以q才是法向厚度。径向差、法向厚度、同一半径处的竖向差不可混用。
- 检查每层剖面无自交、正体积、层间无交叠，且接缝组合连续。厚度差异或极限尺寸使接缝低于筒段下端时，应拒绝该组合或另行设计过渡，不能自动加不明结构补洞。
- 源内外锥角、偏心和间距可能不一致。若用户要求同轴、平行法向等厚重建，保存原形，记录归一化差异；不要宣称逐面复刻了源外形。

## 短接管与附件依赖

- 接管标高明确是法兰顶面、管端还是中心线，使用统一上口基准。角度明确零向与旋转方向。径向中心距是固定输入还是随塔径缩放，遵循用户规则。
- 先生成接管环形实体，再按流道面修齐内端；按管外径切通顶盖各层。法兰内孔、孔组随该侧接管更新；保温穿孔边界由金属管壁/收口封闭。
- 斜切口报告最短、最长及中心线长度，不能拿一个轴向包围盒长度代替全部口部几何。
- 保留人孔和小接管时，检查旧套管是否侵入新流道；矩形槽要从源几何确认开口层级，不能由外观推断需切穿内板。
- 拦截中央开口/塔边缘/双管碰撞、法兰孔边距不足、标高过低与非法尺寸；零孔允许无孔，不能强制造孔。

## 面板升级与缓存

- 旧参数文件只补缺失键，不覆盖已存在值。“源默认值”“当前用户值”“本次专项测试初值”分别记录。
- 接口取消后，对应参数退出UI及有效几何校验；为了旧文件兼容可保留为明确标记的非驱动字段，不能让其继续限制无关尺寸。其他接口的同名类参数不连带停用。
- 改几何算法时提高几何版本，复用键至少考虑参数依赖、几何版本和源/工具身份。只凭输入数值相同不能复用旧修正前的零件。
- 无关组件可沿用经过验证的会话内零件；有新依赖的上部筒段即使主体参数没变，也不能复用旧平口件。不要通过把预期体积改成读回体积来掩盖本应变化的几何。
- 先在候选目录建模并验收，再切换current；失败保持上一有效版本。实际面板入口至少执行一次完整提交，并核对请求参数、退出状态、版本指针及导出。

## 几何与导出验收

1. 微型原生A→B→A：激活确切零件，改变一个会影响接缝的参数，读解析圆边/锥面与真实体积并恢复。旋转体可能没有可枚举顶点，用圆边中心、圆柱/锥面解析参数；不用近似包围盒替代精确尺寸。
2. 当前版本：重开新板件，检查特征及子特征错误、Check3、实体数量、厚度、孔组、齐平口和接合。接缝距离接近0只是必要条件；还需无体积重叠，且对应层组合可并成一个有效实体，避免仅点/线接触。
3. 参数工况：区分几何内核测试和真实SolidWorks原生测试，记录各自范围；前一拓扑版本的多组测试不自动覆盖后一版本。阈值注明单位及适用范围，不当作焊接制造公差。
4. 全装配新增干涉、所有引用路径和源哈希；附件原有内部重叠单列，不能扩大豁免到新板件。
5. STEP保存成功不等于有效。用目标SolidWorks重开，检查完整实体数、体积和Check3；固定导出副本再与已验收的版本STEP比对。

### STEP转换异常的受控处理

仅在明确定位到单个组件的中性格式转换问题时，才考虑替换其等价导出几何：保留原始失败STEP，独立导入候选组件并核对实体身份、数量、体积及关键几何，唯一识别待替换实体，其余实体不变，重开整套候选STEP通过后再提交。无法唯一识别或证明等价就停止替换。不能删掉出错实体凑数，不能跳过Check3，也不能把一次保温转换案例当所有STEP问题的通用修复。

## 历史记录与当前状态

整理知识库或继续项目时，同时读取current.json、其指向的版本verification.json、专项验证证据、交付清单和固定exports副本。用户可能在上次交付后再次通过面板成功修改：旧验收报告仍可有效，但不再代表当前参数；旧STEP副本也可能未重新导出。分别记录差异，不能为了让哈希一致而覆盖用户当前模型或改写历史证据。

发布时应让参数、装配、STEP、报告和清单对应同一版本；若只受托整理知识库，则记录版本差异，不擅自重建或切回历史初值。

## 已验证案例与复用边界

PPG-25案例（2026-09-25）：三层顶盖、左右短接管、法兰与孔组；后续用户确认内外板分别焊接，取消主体上口环板及裙边。专项焊接版本34组件/91实体，原生升高往返、5种接缝工况、6个新板件回读、整塔STEP通过。具体数据和随后500 mm接管标高状态见知识库《SolidWorks雾化塔主体-三层顶盖双接管与焊接参数化复盘》。案例脚本依赖项目坐标、版本、模板及全局目录，不能直接复制为通用宏；不代表强度、热工、焊接工艺或制造验收。
