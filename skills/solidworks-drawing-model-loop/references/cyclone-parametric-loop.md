# 旋风参数化：等面积、偏心斜切、原生方位角与验收

适用：基于参考件创建或修复等面积接口、偏心支管和多实体派生装配。依据2026-09-20 SolidWorks 2026实测。尺寸、PID、模板路径、中文尺寸名和阈值为案例数据，不能直接移植到其他项目。

## 几何含义与参数层级

- “侧出”可能是水平出口，也可能是偏心/近切向接出。分别定义支管方向、绕主轴方位角、两轴最短距离。透视截图不足时回读原件解析轴线；关键缺失量做针对性确认。
- 本案用户最终确认外侧齐边、气体进出口等面积。R4是认可版本，旧174/259管径比例已被替代。2 mm为尺寸验收误差，不是板厚、装配间隙或面积容差。
- 输入等效圆径d、矩形高宽比r：`A0=pi*d²/4; b0=sqrt(A0/r); h0=r*b0`。微调后 `b=b0+Δb; h=h0+Δh; side_ID=sqrt(4*b*h/pi)`。出口必须跟随实际净宽高；等面积要求下不能再独立叠加侧管径微调。竖直溢流管和底部排料管不自动套用此约束。
- 外侧齐边：`e=(main_OD-side_OD)/2+Δe`。仅两管等壁厚时可简化为内径差的一半。零微调满足`e+side_OD/2=main_OD/2`。负的计算偏心、过大出口和法兰包络应检查，不能盲套公式。
- 比例尺寸、壁厚、法兰宽厚、孔组及空间余量分开控制。只放大管径但固定腔高会干涉；本案固定350 mm腔高在输入219 mm时失败。腔高、外伸和法兰包络一起检查，不把有限工况通过外推为任意尺度保证。

## 偏心斜切依赖链

支管、总管开孔、侧法兰圆心和螺栓种子/阵列轴同步偏移。支管端部以总管外圆柱面修剪，开孔以同一偏心圆柱切除；只移动外部管段或转法兰不能得到正确相贯。

R4坐标约定：总管轴Y，未旋转支管沿+Z、圆心x=-e。绕+Y转θ后方向`(sinθ,0,cosθ)`；垂直于该方向的水平向量`u=(cosθ,0,-sinθ)`。轴线上任意点p满足`dot(p,u)=-e`，θ=90°时管沿+X且偏心朝+Z。此坐标映射需按实际模板核对。

原草图用从原点出发的竖直构造线锁定圆心x=0。修复步骤：

1. 在副本解除相关位置方程，保留直径方程。
2. 进入目标草图，仅删对应竖直关系及旧位置尺寸，包括重复参考尺寸；不删除所有约束。
3. 移动圆心到明确正负方向的初值，用`AddHorizontalDimension2`、`AddVerticalDimension2`建立独立坐标尺寸，再链接偏心和高度。
4. 更新螺栓种子，本案横坐标为`PCD/2-e`。阵列轴应跟随偏心圆柱面。
5. 验证完全定义、真实圆心符号、开孔/支管同轴及实际孔组。

`ISketchRelationManager.DeleteRelation`可删指定关系；枚举值按本机类型库核对。本案VERTICAL为5、草图完全定义为3，勿当作跨接口常量。

## 方位角的原生驱动

进口旋转组包括开孔所在筒体、接管和法兰；出口组包括开孔所在上管、侧管和法兰。圆盖是否同转取决于孔组及非轴对称结构。

本机`InsertMoveCopyBody2`创建的旧式XYZ旋转未枚举出可链接尺寸，直接向旧字段输入公式也失败。编辑特征启用Euler角，给非零初值并提交后，枚举Yaw/Pitch/Roll尺寸，再用EquationMgr链接。本案中文尺寸为`偏航@特征名`，必须实际查询。

本案直接新增零角方程失败，`偏航=方位角+360`通过，并验证0°及多个其他方位。这是本机单轴旋转兼容处理，不代表所有版本禁止0°。先复现再采用，验证真实轴线与往返状态。全局角度数字在本例按度使用，API通常为弧度；本机`0deg`写法曾失败，不盲套单位字符串。

官方依据：[Move/Copy尺寸与Euler方程支持](https://help.solidworks.com/2023/english/whatsnew/c_wn2023_parts_dim_support_move_copy.htm)。功能支持不等于旧API创建的特征自动具有同样的尺寸。

## 方程式与COM避坑

|症状|处理|
|---|---|
|方程变了但几何未更新|`ActivateDoc3(绝对路径)`后重新绑定文档和EquationMgr。先证明实际几何变化，再测装配；两个未更新体积相同是假阳性。|
|参考尺寸误作驱动尺寸，方程树报错|重合点自动合并可能留下参考尺寸。受控副本中备份/解除相关方程再辨认DrivenState，恢复独立驱动尺寸；不要强行把所有尺寸改为驱动。方程链接中的DrivenState不能直接分类。|
|SetEquation返回None导致assert失败|本机setter无返回值；回读方程、求值和实际几何。Add2返回索引，两者语义不同。|
|tuple object is not callable|动态COM无参属性/方法不一致，GetEdges/GetFaces等使用现有value()适配器。|
|sqrt方程无效|本机SolidWorks表达式用`sqr`，Python仍用`sqrt`。|
|大量COM调用很慢|先建变量名→索引映射，只改变化的行，批量求值重建，finally恢复自动重建设置。避免每次set都全表扫描及重写全部方程。|
|UI确认后立即查不到尺寸|先确认PropertyManager退出，再枚举新尺寸；输入动作返回不代表特征提交完成。|

## 副本、保存实体与装配

- 不同目录同名零件同时打开可能失败，新版本用唯一文件名，保存副本后核对原文档身份。
- 本机保存实体特征类型是`CreateAssemFeat`，不是猜测的`SaveBody`。只在副本核对并移除旧输出特征，再生成独立目录中的派生件/装配，避免继续写旧目录。
- `CreateSaveBodyFeature`可建立共同原点派生组件。模板偏好临时修改后finally恢复。保存实体会重命名Body.Name，后续验收用持久引用或经过唯一性验证的几何识别。
- 母件改参→重建保存→组件及装配重建→几何比较→恢复保存→重开。角度变化不改变体积，要比较轴线、位置、六向极值。非单位组件变换必须先统一到装配坐标系；本案共同原点组件可直接比较。

## 验收与可证明范围

1. 测用户失败输入、代表性放缩、非直角/零角、宽高及偏心微调、恢复状态；每个相关工况检查有效实体、错误和干涉。
2. BREP矩形净口角点计算净面积，解析圆柱半径计算侧口净面积，轴线计算方位及最短距离，外半径+偏心计算齐边。开孔同轴不是CFD性能或完整流道连通性证明。
3. GetBodyBox仅用于干涉候选粗筛。`IModeler.CheckInterferenceBetweenTwoBodies(...,False)`排除仅接触，再检查交叠体积。R4的0.01 mm³阈值是数值筛选约定，不是2 mm验收误差的单位换算。
4. 重开原生母件/装配，STEP用不同文件名导入避免重名。检查实体数、Check2、合理体积差、关键尺寸及六向精确极值。极值一致不证明内部拓扑全同，需结合孔口及解析面验证。
5. 本案按唯一体积排序配对实体，重复体积零件不能照搬；优先持久身份或几何签名。
6. ViewZoomTo2本案产生裁切不当的局部图；选上部实体→ViewZoomToSelection→清选择→SaveBMP更可靠。必须实际看图，修正预览后重打包。

`validation.json`保存219基准、45°/135°及宽高/偏心微调、300 mm的180°/0°、恢复219；`delivery_verification.json`保存230 mm、30°/150°装配联动及重开/STEP。`development/repair.py`为偏心草图迁移，`validate.py`为几何验收，`deliver.py`为关联及回读。

案例脚本包含历史PID/路径，部分为一次性迁移步骤，不能原样当通用生成器运行。以R4和对应证据为准，早期R1～R3的通过范围不能覆盖后来修正的需求。用户认可的是本次几何和参数化交付，不扩展为CFD、压力容器或制造认证。
